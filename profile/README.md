# VisionX25

**Advancing AI Through Research, Open Data & Innovation**

VisionX25 is an independent open-source initiative based in Bogura, Bangladesh. We explore artificial intelligence, machine learning, and computer vision through practical projects, research experiments, and shared resources.

## Current project

### [OpenDatasets](https://github.com/VisionX25/OpenDatasets)

An open-source catalog for discovering machine learning datasets, browsing categories, and inspecting structured metadata and source references.

- **27 dataset metadata records** as of 29 October 2026.
- Search, category browsing, and individual dataset detail pages.
- Metadata schema validation and automated catalog checks.
- Built with React, TypeScript, and Python.

Verification refers to metadata and cited sources. It does not guarantee the quality, labels, or suitability of the underlying datasets.

[Explore the repository](https://github.com/VisionX25/OpenDatasets) · [Contribution guide](https://github.com/VisionX25/OpenDatasets/blob/main/CONTRIBUTING.md) · [Roadmap](https://github.com/VisionX25/OpenDatasets/blob/main/ROADMAP.md)
